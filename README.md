# Tulchyn Light Alert

Персональний Telegram-бот для сповіщень про графік відключень за адресою:
**м. Тульчин, вул. Генерала Кульчицького, 45**.

## Заплановані функції

- `/start` — реєстрація чату;
- `/status` — найближча подія за останнім отриманим графіком;
- `/schedule` — графік на сьогодні;
- нагадування за 30 хвилин до початку та завершення планового відключення;
- повідомлення про зміну графіка;
- повідомлення про помилку отримання даних, щоб не видавати старий графік за актуальний.

## Статус розробки

Telegram-бот ще не запущений. Перед написанням інтеграції потрібно визначити, який мережевий запит сайт Вінницяобленерго виконує після пошуку адреси та як виглядає відповідь із графіком. Автоматично читати сторінку напряму наразі не вдалося, тому не можна безпечно вигадувати API-адресу або формат даних.

## Що потрібно для підключення джерела

У браузері відкрий сайт https://disconnection.voe.com.ua/, натисни F12 → Network → Fetch/XHR, очисти список запитів, потім повтори пошук адреси. Знайди запит, який повертає таблицю графіка. Надішли мені:
- Request URL;
- Request Method;
- назви полів у Payload (значення адреси можна замаскувати);
- Response із часовими інтервалами.

Не надсилай Cookies, Authorization headers, токени чи інші секрети.

## Безпека

Telegram-токен зберігати тільки в GitHub Actions Secrets як `BOT_TOKEN`. Не додавати токен у файли, коміти, скриншоти або повідомлення.
